How to use TerraLink Studio

  1. Take off and scan. Press Take off, then fly the UAV over the ground the UGV must cross. The map appears under the UAV. (With a saved map there is nothing to scan: skip to step 2.)
  2. Pick a goal. Press Set goal (or G), then click a green spot in any view. The UGV plans a route and drives there by itself.
  3. Watch. Use the views (the menu in each view's corner) to follow the action: free orbit, top-down map, behind or inside either robot.

Xbox-style controller

Plug it into Windows, then press any button once so the browser notices it.

  • Left stick: up/down climb/descend, left/right turn
  • Right stick: fly forward/back and sideways
  • LT (hold): slow, precise mode
  • B emergency stop · A release it
  • Y: switch UAV ⇄ UGV by hand
  • LB / RB: previous / next view · Start: layout · Back: goal tool

UGV by hand: left stick up/down drives, right stick left/right steers.

Keyboard & mouse

  • WSAD fly forward/back/left/right · RF up/down · QE turn
  • Shift slow mode · Space emergency stop / release
  • G goal tool, then click · Esc cancel · M UAV ⇄ UGV by hand
  • 1–7 change the main view · L layout · H this help
  • Orbit view: drag rotates · right-drag or Shift-drag pans · wheel zooms
  • Top view: drag pans · wheel zooms

Safety: the UAV stops by itself if this page stops talking to it (closed tab, lost link), cannot leave the site or fly outside its height limits, and the emergency stop also cancels the UGV's goal. The simulator runs at roughly half real time on this machine, so everything reacts slowly.
